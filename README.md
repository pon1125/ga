# DUNGEON VEIL

ブラウザで遊べる2Dリアルタイム・ダンジョン探索ゲームです。

## 起動方法
1. `index.html` をブラウザで開く
2. 「探索を開始」を押す

## 操作
- WASD / 矢印キー：移動
- SPACE：攻撃
- SHIFT：ダッシュ
- 右側の「使う」：回復ポーション

## GitHub Pagesで公開
1. GitHubで新しいPublicリポジトリを作成
2. このフォルダ内の `index.html`, `style.css`, `game.js`, `README.md` をアップロード
3. Settings → Pages → Deploy from a branch
4. Branchを `main`、Folderを `/ (root)` にしてSave
5. 表示されたURLから遊べます

※最初のプロトタイプです。階層移動・敵AI・アイテムなどを今後拡張できます。
